# REST API

Generated by `scripts/export_docs.py` from the running app. With the app running, the interactive version is at `/api/docs` (Swagger UI) and the machine-readable one at `/api/openapi.json` (also saved as [`openapi.json`](openapi.json)).

Long operations (generate, re-voice, video...) return a `job` object immediately; poll `GET /api/jobs/{job_id}` for progress. A project accepts one job at a time (a second request gets `409`). The server binds to localhost and has no authentication: it is a local tool.

## Meta, setup and tuning

| Method | Path | What it does |
|---|---|---|
| `GET` | `/api/config` | Everything the UI needs to build its forms: languages, voices, delivery styles, defaults, models, upload limit, key status and whether ffmpeg is installed. |
| `GET` | `/api/doctor` | Run the setup check and return one row per check (see `doctor.run_doctor`). |
| `GET` | `/api/extras` | Tell the UI which optional features are available (it shows the Learn, Ask and Quality tabs only if this answers). |
| `GET` | `/api/health` | Is the server up? `mock` says whether demo mode is on. |
| `POST` | `/api/preview` | Synthesise a short sample of one voice (WAV) so a voice can be heard before it is chosen as a host. |
| `POST` | `/api/setup/keys` | Save keys to the local .env and apply them immediately. Only accepted from this computer; keys are never returned. |
| `GET` | `/api/tuning` | The current tuning values with their defaults, the preset names and the tuning file path. |
| `PUT` | `/api/tuning` | Apply a tuning preset or individual values. Unknown names are rejected and values are clamped to safe ranges. |

## Projects (episodes)

| Method | Path | What it does |
|---|---|---|
| `GET` | `/api/projects` | Summaries of all projects, newest first. |
| `POST` | `/api/projects` | Create a project from an uploaded PDF/text file or pasted text plus its settings (multipart form), then start the generation job. |
| `DELETE` | `/api/projects/{pid}` | Delete a project and its files; refused while one of its jobs is running. |
| `GET` | `/api/projects/{pid}` | One project together with its active or latest job (the UI polls this to show progress). |
| `GET` | `/api/projects/{pid}/files/{relpath}` | Serve a file of a project (segment audio, final audio, transcripts, video). Only those folders are public, and `download=1` sends the file as an attachment with a readable name. |

## Episode actions

| Method | Path | What it does |
|---|---|---|
| `POST` | `/api/projects/{pid}/assemble` | Rebuild the final audio, transcripts and chapter marks from every segment's current version. |
| `POST` | `/api/projects/{pid}/remix` | Rebuild the final mix with the current tuning, re-using the cached voice clips (no voice credits). |
| `POST` | `/api/projects/{pid}/resume` | Continue generating from where an interrupted or failed run stopped; finished steps are skipped. |
| `POST` | `/api/projects/{pid}/validate` | Quality report for an episode. With `deep=true` every segment is also re-checked by the model. |
| `POST` | `/api/projects/{pid}/voice` | Record the audio and assemble the episode for a project whose script is waiting for review. |

## Segments (redo, edit, history)

| Method | Path | What it does |
|---|---|---|
| `POST` | `/api/projects/{pid}/segments/{index}/edit-turn` | Hand-edit one line of a segment's script (background job; only that line is re-recorded). |
| `POST` | `/api/projects/{pid}/segments/{index}/regenerate` | Rewrite or re-voice one segment (background job; see `RegenerateBody`). |
| `POST` | `/api/projects/{pid}/segments/{index}/revert` | Make an earlier version of a segment the current one (background job). |

## Video

| Method | Path | What it does |
|---|---|---|
| `POST` | `/api/projects/{pid}/video` | Start building the narrated MP4 (background job). The body may override the video settings. |
| `POST` | `/api/projects/{pid}/video/segments/{index}/regenerate` | Redraw the visuals of a single segment, optionally following an instruction (background job). |

## Study pack, Ask the hosts, Quality

| Method | Path | What it does |
|---|---|---|
| `DELETE` | `/api/projects/{pid}/ask` | Delete the saved questions and answers of this episode. |
| `GET` | `/api/projects/{pid}/ask` | The questions already asked about this episode, with their answers and sources. |
| `POST` | `/api/projects/{pid}/ask` | Answer one question (see `ask.answer_question`). Only one question per episode is answered at a time. |
| `GET` | `/api/projects/{pid}/ask/{n}/audio` | The recorded answer number `n` as WAV. |
| `GET` | `/api/projects/{pid}/insights` | The numbers behind the Quality tab (see `insights.compute_insights`); `validation=0` skips re-running the validator. |
| `GET` | `/api/projects/{pid}/insights/report` | The printable Quality evidence report (HTML); `download=1` sends it as a file. |
| `GET` | `/api/projects/{pid}/learn` | Status of the study pack: none, working, ready (with the pack) or error. |
| `POST` | `/api/projects/{pid}/learn` | Build the study pack in the background (or return the existing one unless `regenerate` is true). |
| `GET` | `/api/projects/{pid}/learn/sheet` | The printable study sheet (HTML); `download=1` sends it as a file. |

## Jobs

| Method | Path | What it does |
|---|---|---|
| `GET` | `/api/jobs/{job_id}` | Status and progress of a background job. |
| `POST` | `/api/jobs/{job_id}/cancel` | Ask a running job to stop at its next safe point. |
